# Manage your time
The TaskManager application allows you to manage tasks and plan them in your agenda or place them on to-do lists!  
This application was written in Java, and uses SQLite to communicate with a database and elements from the JavaFX package for user controls.  

# Get started!
To try it out, download the runnable .jar file from the repository.  
Keep in mind that running it will require Java version 1.8 or later to be installed on your computer.  
The application will create a local database for your personal tasks!
